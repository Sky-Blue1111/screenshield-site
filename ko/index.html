화면은 공유하고, 비밀은 지키세요.

화면을 공유하기 전에 이메일, 전화번호 같은 개인정보와 카드 번호, API 키를 블러 처리하세요. ScreenShield가 페이지 안에서 바로 민감 정보를 숨기기 때문에 회의 참가자도, 녹화 영상을 보는 사람도, 라이브 방송 시청자도 볼 수 없어요.

Chrome Web Store

영업 데모, 고객 지원 통화, 튜토리얼, 라이브 방송, 그리고 브라우저 탭을 공유하는 모든 Zoom, Google Meet, Microsoft Teams 회의를 위해 만들었어요.

무료, 제한 없음

  • 클릭해서 블러: 텍스트, 이미지, 표 셀, 버튼 등 무엇이든 클릭하면 블러 처리돼요. 다시 클릭하면 해제돼요.
  • 영역 그리기: 사각형을 드래그해 차트나 사이드바 같은 영역 전체를 블러 처리해요.
  • 비슷한 항목 블러: 목록에서 이메일 하나를 클릭하면 이메일 열 전체가 블러 처리돼요.
  • 저장된 블러: 블러는 사이트별로 저장되며 다시 방문하면 복원돼요.
  • 블러 강도: 원하는 만큼 강하게 블러 처리할 수 있어요.
  • 검은 박스: 블러 대신 검은색으로 완전히 가려서 아무것도 복원할 수 없어요.
  • 이 사이트에서 탭 제목 숨기기: 탭의 제목과 아이콘을 바꿔 아무도 알아볼 수 없게 해요.
  • 이 페이지에서 민감 정보 스캔: 어떤 페이지에서든 이메일과 전화번호를 찾아 한 번에 모두 블러 처리해요.
  • 긴급 숨김 키: Alt+Shift+H를 누르면 화면 전체가 즉시 숨겨져요. 다시 누르면 다시 표시돼요.
  • 실행 취소와 다시 실행, 단축키, 마우스 오른쪽 버튼 메뉴도 지원해요.

Pro: 매일 화면을 공유하는 분을 위해

  • 모든 사이트에서 자동 감지: 아무것도 클릭하지 않아도 페이지가 로드되는 동안 민감 정보가 숨겨져요. ScreenShield는 이메일, 전화번호, 카드 번호(Luhn 알고리즘으로 확인), IBAN(체크섬 검증), 미국 사회보장번호(SSN), IP 주소(IPv4 및 IPv6), 주요 서비스의 API 키, 액세스 토큰, 토큰(JWT), 개인 키, 데이터베이스 URL, 링크 내 비밀 정보, 암호화폐 지갑 주소를 찾아내고, 설정을 켜면 금액도 찾아요.
  • 내 키워드: 고객 이름, 프로젝트 코드명, 계좌 번호를 숨기세요. 정규 표현식을 지원하며, 사용하기 전에 패턴을 테스트해 볼 수 있어요.
  • 발표 모드: 열려 있는 모든 탭에서 민감 정보를 숨기고 다른 탭의 제목을 가려요. 웹에서 Google Meet, Zoom, Microsoft Teams로 공유를 시작하면 자동으로 켜지고, 공유를 멈추면 꺼져요. 데스크톱 회의 앱에서 공유하나요? Alt+Shift+M을 누르세요.
  • 안전한 스크린샷 찍기: 민감 정보가 모두 숨겨진 상태로 스크린샷을 찍은 뒤 PNG로 다운로드하거나 복사할 수 있어요.
  • 백업: 설정과 저장된 블러를 파일로 내보내고 다른 컴퓨터에서 가져올 수 있어요.

Pro 요금은 월간 $4.99, 연간 $29.99이며, $49를 한 번만 결제하면 평생 이용할 수 있어요. 7일 동안 무료로 체험해 보세요.

결제는 ExtensionPay와 Stripe가 안전하게 처리해요. 월간 또는 연간 플랜은 언제든지 취소할 수 있어요.

사용 방법

  1. ScreenShield를 툴바에 고정하세요.
  2. ScreenShield를 열고 '클릭해서 블러', '영역 그리기', '비슷한 항목 블러' 중 하나를 선택하거나 '이 페이지에서 민감 정보 스캔'을 누르세요.
  3. 화면을 공유하세요. Pro를 사용하면 발표 모드가 자동으로 켜져요.

처음 사용하시나요? 환영 페이지에서 가짜 데이터로 채운 연습 페이지를 열 수 있어요.

개인정보 보호

  • 모든 감지와 블러 처리는 내 컴퓨터에서 이루어져요. 페이지 내용은 브라우저 밖으로 나가지 않아요.
  • 분석 도구, 광고, 추적이 없어요. 무료 플랜은 계정이 필요 없어요.
  • 설정과 저장된 블러는 Chrome이 내 컴퓨터에 저장해요.
  • 네트워크 연결은 Pro 구매를 확인하고 처리하기 위한 extensionpay.com 하나뿐이에요. Pro를 구매하면 결제에 사용한 이메일 주소를 ExtensionPay가 보관해요.
  • ScreenShield는 페이지가 로드되는 동안 블러를 다시 적용하고 민감 정보를 숨기기 위해 방문하는 페이지에서 실행돼요.

개인정보처리방침: https://sky-blue1111.github.io/screenshield-site/privacy

알아 두세요

  • Chrome은 chrome:// 페이지, Chrome Web Store, 다른 확장 프로그램의 페이지에서 확장 프로그램이 실행되는 것을 허용하지 않아요.
  • 캔버스에 그려진 텍스트(Google Docs 등)나 이미지 속 글자는 읽을 수 없어요. '영역 그리기'로 가리세요.
  • 자동 감지는 유출 위험을 낮춰 주지만, 모든 것을 잡아내는 도구는 없어요. 매우 민감한 내용을 공유하기 전에는 화면을 한 번 더 확인하세요.

단축키

  • Alt+Shift+S: 블러 처리할 대상 선택 시작/중지
  • Ctrl+Shift+X (Mac: Cmd+Shift+X): 페이지의 블러 모두 제거
  • Alt+Shift+M: 발표 모드 켜기/끄기 (Pro)
  • Alt+Shift+H: 화면 전체를 즉시 숨기기
  • Esc: 선택 중지. Ctrl+Z / Ctrl+Shift+Z: 실행 취소 / 다시 실행

단축키는 chrome://extensions/shortcuts 에서 변경할 수 있어요.
