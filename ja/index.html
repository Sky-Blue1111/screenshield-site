画面は共有しても、秘密は共有しない。

画面を共有する前に、メールアドレスや電話番号などの個人情報、カード番号、API キーをぼかしましょう。ScreenShield はページの中で直接機密情報を隠すので、会議の参加者にも、録画を見る人にも、ライブ配信の視聴者にも見られることはありません。

Chrome Web Store

営業デモ、カスタマーサポートの通話、チュートリアル、ライブ配信、そしてブラウザのタブを共有するすべての Zoom、Google Meet、Microsoft Teams の会議のために作られています。

無料で、制限なし

  • クリックでぼかす： テキスト、画像、表のセル、ボタンなど、クリックしたものをぼかします。もう一度クリックすると解除できます。
  • 範囲を指定： ドラッグして四角形を描き、グラフやサイドバーなどの領域をまとめてぼかします。
  • 似た項目をぼかす： リスト内のメールアドレスを 1 つクリックすると、メールアドレスの列全体をぼかします。
  • 保存したぼかし： ぼかしはサイトごとに保存され、次に開いたときに復元されます。
  • ぼかしの強さ： ぼかしの強さは自由に調整できます。
  • 黒塗り： ぼかしの代わりに黒一色で覆い隠すので、元の内容は復元できません。
  • このサイトのタブ名を隠す： タブのタイトルとアイコンを置き換えて、誰にも読めないようにします。
  • このページの機密情報をスキャン： どのページでもメールアドレスと電話番号を見つけ、まとめてぼかします。
  • 緊急非表示キー： Alt+Shift+H で画面全体をすぐに隠します。もう一度押すと再表示します。
  • 元に戻す／やり直す、キーボード ショートカット、右クリックメニューにも対応しています。

Pro：毎日画面を共有する方に

  • すべてのサイトで自動検出： ページの読み込み中に、クリック不要で機密情報を隠します。ScreenShield は、メールアドレス、電話番号、カード番号（Luhn アルゴリズムで確認）、IBAN（チェックサムを検証）、米国の社会保障番号（SSN）、IP アドレス（IPv4 と IPv6）、主要サービスの API キー、アクセストークン、トークン（JWT）、秘密鍵、データベース URL、リンク内のシークレット、暗号資産ウォレットのアドレスを検出します。設定をオンにすれば、金額も検出できます。
  • カスタムキーワード： 顧客名、プロジェクトのコードネーム、口座番号などを隠せます。正規表現にも対応し、使う前にパターンをテストできます。
  • プレゼンモード： 開いているすべてのタブで機密情報を隠し、ほかのタブのタイトルを伏せます。ウェブ版の Google Meet、Zoom、Microsoft Teams で共有を始めると自動でオンになり、共有を終えると自動でオフになります。デスクトップの会議アプリから共有する場合は、Alt+Shift+M を押してください。
  • 安全なスクリーンショットを撮る： 機密情報をすべて隠した状態で撮影し、PNG でダウンロードしたりコピーしたりできます。
  • バックアップ： 設定と保存したぼかしをファイルにエクスポートし、別のパソコンでインポートできます。

使い方

  1. ScreenShield をツールバーに固定します。
  2. ScreenShield を開き、「クリックでぼかす」「範囲を指定」「似た項目をぼかす」から選ぶか、「このページの機密情報をスキャン」をクリックします。
  3. 画面を共有します。Pro なら、プレゼンモードが自動でオンになります。

初めての方は、ウェルカムページからダミーデータ入りの練習ページを開けます。

プライバシー

  • 検出とぼかしの処理はすべてお使いのパソコン上で行われます。ページの内容がブラウザの外に出ることはありません。
  • アクセス解析、広告、トラッキングはありません。無料プランはアカウント不要です。
  • 設定と保存したぼかしは、Chrome がお使いのパソコンに保存します。
  • 通信するのは、Pro の購入の確認と処理のための extensionpay.com だけです。Pro を購入すると、支払いに使ったメールアドレスが ExtensionPay に保管されます。
  • ScreenShield は、ページの読み込み中にぼかしを再適用して機密情報を隠すため、閲覧中のページで動作します。

プライバシー ポリシー：https://sky-blue1111.github.io/screenshield-site/privacy

注意事項

  • Chrome の仕様上、chrome:// で始まるページ、Chrome Web Store、ほかの拡張機能のページでは拡張機能を実行できません。
  • キャンバスに描画されたテキスト（Google Docs など）や画像内の文字は読み取れません。「範囲を指定」で覆ってください。
  • 自動検出で漏えいのリスクは下がりますが、すべてを検出できるツールはありません。機密性の高い内容を共有する前に、画面を確認してください。

キーボード ショートカット

  • Alt+Shift+S： ぼかす箇所の選択を開始／終了
  • Ctrl+Shift+X (Mac: Cmd+Shift+X)：ページ上のぼかしをすべて解除
  • Alt+Shift+M： プレゼンモードのオン／オフ（Pro）
  • Alt+Shift+H： 画面全体をすぐに隠す
  • Esc： 選択を終了。Ctrl+Z / Ctrl+Shift+Z：元に戻す / やり直す

ショートカットは chrome://extensions/shortcuts で変更できます。
