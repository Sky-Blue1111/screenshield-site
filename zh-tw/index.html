Chrome Web Store

專為業務展示、客服通話、教學、直播，以及所有需要分享瀏覽器分頁的 Zoom、Google Meet 或 Microsoft Teams 會議打造。

免費，沒有限制

  • 點選模糊： 點選任何文字、圖片、表格儲存格或按鈕即可模糊，再點一次即可取消模糊。
  • 框選區域： 拖曳出一個矩形，模糊整塊區域，例如圖表或側邊欄。
  • 模糊同類： 點選清單中的一個電子郵件，整欄電子郵件都會被模糊。
  • 已儲存的模糊： 模糊會依網站分別儲存，再次造訪時自動還原。
  • 模糊強度： 可依需要調整模糊程度。
  • 黑條： 用純黑色塊取代模糊來遮蓋內容，什麼也還原不出來。
  • 在此網站隱藏分頁標題： 取代分頁的標題和圖示，讓任何人都看不到原本的標題。
  • 掃描此頁面中的敏感資訊： 找出任何頁面上的電子郵件和電話號碼，一次全部模糊。
  • 緊急隱藏鍵： 按下 Alt+Shift+H 立即隱藏整個畫面，再按一次即可重新顯示。
  • 支援復原和重做、鍵盤快速鍵和右鍵選單。

Pro：為每天都要分享螢幕的人打造

  • 所有網站自動偵測： 頁面載入時就會自動隱藏敏感資訊，不必點選任何東西。ScreenShield 能偵測電子郵件、電話、信用卡號（以 Luhn 演算法驗證）、IBAN（經檢查碼驗證）、美國社會安全號碼（SSN）、IP 位址（IPv4 和 IPv6）、常見服務的 API 金鑰、存取權杖、權杖（JWT）、私密金鑰、資料庫 URL、連結中的機密資訊、加密貨幣錢包地址；開啟相關選項後，還能偵測金額。
  • 自訂關鍵字： 隱藏客戶名稱、專案代號或帳號。支援規則運算式，使用前還能先測試比對結果。
  • 簡報模式： 隱藏所有已開啟分頁中的敏感資訊，並遮蓋其他分頁的標題。在網頁版 Google Meet、Zoom 或 Microsoft Teams 開始分享時會自動開啟，停止分享後自動關閉。使用桌面版會議應用程式分享？按下 Alt+Shift+M 即可。
  • 擷取安全截圖： 截圖中所有敏感內容都已隱藏，可下載為 PNG 或直接複製。
  • 備份： 將設定和已儲存的模糊匯出成檔案，再到另一台電腦匯入。

使用方式

  1. 將 ScreenShield 固定到工具列。
  2. 開啟 ScreenShield，選擇「點選模糊」、「框選區域」或「模糊同類」，或點選「掃描此頁面中的敏感資訊」。
  3. 分享螢幕。使用 Pro 時，簡報模式會自動開啟。

第一次使用？歡迎頁面會帶你開啟一個滿是假資料的練習頁面。

隱私權

  • 所有偵測和模糊處理都在你的電腦上進行，頁面內容絕不會離開你的瀏覽器。
  • 沒有分析工具、沒有廣告，也不追蹤。免費版不需要帳號。
  • 你的設定和已儲存的模糊由 Chrome 儲存在你的電腦上。
  • 唯一的網路連線是 extensionpay.com，用來確認及處理 Pro 購買。如果你購買 Pro，ExtensionPay 會保留你付款時使用的電子郵件地址。
  • ScreenShield 會在你造訪的頁面上執行，以便在頁面載入時重新套用你的模糊並隱藏敏感資訊。

隱私權政策：https://sky-blue1111.github.io/screenshield-site/privacy

注意事項

  • Chrome 不允許擴充功能在 chrome:// 頁面、Chrome Web Store 或其他擴充功能的頁面上執行。
  • 以畫布繪製的文字（例如 Google Docs）或圖片中的文字無法讀取，請改用「框選區域」遮蓋。
  • 自動偵測能降低外洩風險，但沒有任何工具能抓到所有內容。分享高度敏感的內容前，請先檢查一次畫面。

鍵盤快速鍵

  • Alt+Shift+S： 開始或停止選取要模糊的內容
  • Ctrl+Shift+X (Mac: Cmd+Shift+X)：清除頁面上的所有模糊
  • Alt+Shift+M： 開啟或關閉簡報模式（Pro）
  • Alt+Shift+H： 立即隱藏整個畫面
  • Esc： 停止選取。Ctrl+Z / Ctrl+Shift+Z：復原 / 重做

你可以在 chrome://extensions/shortcuts 變更任何快速鍵。
