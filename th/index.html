แชร์หน้าจอได้ โดยไม่ต้องแชร์ความลับ

เบลออีเมล เบอร์โทรศัพท์ เลขบัตร และคีย์ API ก่อนแชร์หน้าจอ ScreenShield ซ่อนข้อมูลสำคัญไว้ในหน้าเว็บโดยตรง ผู้ร่วมประชุม คนที่ดูวิดีโอที่คุณบันทึก หรือผู้ชมไลฟ์สตรีมของคุณจึงไม่มีทางเห็นข้อมูลเหล่านี้

Chrome Web Store

เหมาะสำหรับการเดโมสินค้าเพื่อการขาย การโทรดูแลลูกค้า วิดีโอสอนใช้งาน ไลฟ์สตรีม และทุกการประชุมผ่าน Zoom, Google Meet หรือ Microsoft Teams ที่คุณแชร์แท็บเบราว์เซอร์

ฟรี ไม่จำกัด

  • คลิกเพื่อเบลอ: คลิกข้อความ รูปภาพ ช่องในตาราง หรือปุ่มใดก็ได้เพื่อเบลอ คลิกอีกครั้งเพื่อยกเลิกเบลอ
  • เลือกพื้นที่: ลากเป็นกรอบสี่เหลี่ยมเพื่อเบลอทั้งบริเวณ เช่น กราฟหรือแถบด้านข้าง
  • เบลอที่คล้ายกัน: คลิกอีเมลหนึ่งอันในรายการ แล้วอีเมลทั้งคอลัมน์จะถูกเบลอตาม
  • การเบลอที่บันทึกไว้: บันทึกแยกตามเว็บไซต์ และกลับมาเมื่อคุณเข้าเว็บไซต์นั้นอีกครั้ง
  • ความเข้มของการเบลอ: ปรับให้เบลอเข้มแค่ไหนก็ได้ตามต้องการ
  • แถบดำ: ปิดทับด้วยสีดำทึบแทนการเบลอ จึงไม่มีอะไรให้กู้คืนได้
  • ซ่อนชื่อแท็บในเว็บไซต์นี้: แทนที่ชื่อและไอคอนของแท็บ ไม่ให้ใครอ่านออก
  • สแกนหาข้อมูลสำคัญในหน้านี้: ค้นหาอีเมลและเบอร์โทรศัพท์ในหน้าใดก็ได้ แล้วเบลอทั้งหมดในครั้งเดียว
  • ปุ่มฉุกเฉิน: กด Alt+Shift+H เพื่อซ่อนทั้งหน้าจอทันที กดอีกครั้งเพื่อแสดงกลับมา
  • เลิกทำและทำซ้ำ แป้นพิมพ์ลัด และเมนูคลิกขวา

Pro สำหรับคนที่แชร์หน้าจอทุกวัน

  • ตรวจจับอัตโนมัติในทุกเว็บไซต์: ข้อมูลสำคัญจะถูกซ่อนตั้งแต่หน้าเว็บกำลังโหลด โดยที่คุณไม่ต้องคลิกอะไรเลย ScreenShield ตรวจพบอีเมล เบอร์โทรศัพท์ เลขบัตร (ตรวจด้วยอัลกอริทึม Luhn) IBAN (ยืนยันด้วยเช็กซัม) SSN (หมายเลขประกันสังคมของสหรัฐฯ) ที่อยู่ IP (IPv4) ที่อยู่ IPv6 คีย์ API ของบริการยอดนิยม โทเค็นการเข้าถึง โทเค็น (JWT) คีย์ส่วนตัว URL ฐานข้อมูล รหัสลับในลิงก์ ที่อยู่กระเป๋าคริปโต และจำนวนเงินหากคุณเปิดใช้
  • คำสำคัญของคุณ: ซ่อนชื่อลูกค้า ชื่อรหัสโปรเจกต์ หรือเลขบัญชี รองรับนิพจน์ทั่วไป และทดสอบรูปแบบก่อนใช้งานจริงได้
  • โหมดนำเสนอ: ซ่อนข้อมูลสำคัญในทุกแท็บที่เปิดอยู่ และปิดบังชื่อแท็บอื่นๆ ของคุณ เปิดเองเมื่อคุณเริ่มแชร์หน้าจอใน Google Meet, Zoom หรือ Microsoft Teams บนเว็บ และปิดเองเมื่อคุณหยุดแชร์ หากแชร์จากแอปประชุมบนเดสก์ท็อป ให้กด Alt+Shift+M
  • จับภาพหน้าจอแบบปลอดภัย: ได้ภาพหน้าจอที่ซ่อนทุกอย่างไว้แล้ว จากนั้นดาวน์โหลดเป็น PNG หรือคัดลอก
  • การสำรองข้อมูล: ส่งออกการตั้งค่าและการเบลอที่บันทึกไว้เป็นไฟล์ แล้วนำเข้าในคอมพิวเตอร์เครื่องอื่น

Pro มีแพ็กเกจรายเดือน $4.99 ต่อเดือน รายปี $29.99 ต่อปี หรือตลอดชีพ $49 จ่ายครั้งเดียว ทดลองใช้ฟรี 7 วัน

ชำระเงินอย่างปลอดภัยผ่าน ExtensionPay และ Stripe คุณยกเลิกแพ็กเกจรายเดือนหรือรายปีได้ทุกเมื่อ

วิธีการทำงาน

  1. ปักหมุด ScreenShield ไว้บนแถบเครื่องมือ
  2. เปิด ScreenShield แล้วเลือก “คลิกเพื่อเบลอ” “เลือกพื้นที่” หรือ “เบลอที่คล้ายกัน” หรือสแกนหน้าเว็บ
  3. แชร์หน้าจอ หากใช้ Pro โหมดนำเสนอจะเปิดเอง

สำหรับผู้ใช้ใหม่ หน้าต้อนรับจะเปิดหน้าฝึกใช้งานที่เต็มไปด้วยข้อมูลปลอม

ความเป็นส่วนตัว

  • การตรวจจับและการเบลอทั้งหมดเกิดขึ้นบนคอมพิวเตอร์ของคุณ เนื้อหาของหน้าเว็บไม่เคยออกไปจากเบราว์เซอร์
  • ไม่มีระบบวิเคราะห์ ไม่มีโฆษณา ไม่มีการติดตาม แพ็กเกจฟรีไม่ต้องใช้บัญชี
  • Chrome จัดเก็บการตั้งค่าและการเบลอที่บันทึกไว้บนคอมพิวเตอร์ของคุณ
  • การเชื่อมต่อเครือข่ายเพียงอย่างเดียวคือไปที่ extensionpay.com เพื่อตรวจสอบและดำเนินการซื้อ Pro หากคุณซื้อ Pro ทาง ExtensionPay จะเก็บอีเมลที่คุณใช้ชำระเงินไว้
  • ScreenShield ทำงานบนหน้าเว็บที่คุณเข้าชม เพื่อใช้การเบลอของคุณอีกครั้งและซ่อนข้อมูลสำคัญขณะที่หน้าเว็บกำลังโหลด

นโยบายความเป็นส่วนตัว: https://sky-blue1111.github.io/screenshield-site/privacy

ข้อควรรู้

  • Chrome ไม่อนุญาตให้ส่วนขยายทำงานในหน้า chrome:// ใน Chrome Web Store หรือในหน้าของส่วนขยายอื่น
  • ข้อความที่วาดบน canvas (เช่นใน Google Docs) หรืออยู่ในรูปภาพจะอ่านไม่ได้ ให้ใช้ “เลือกพื้นที่” ปิดทับ
  • การตรวจจับอัตโนมัติช่วยลดความเสี่ยงที่ข้อมูลจะรั่วไหล แต่ไม่มีเครื่องมือใดตรวจจับได้ทุกอย่าง โปรดตรวจดูหน้าจอก่อนแชร์ข้อมูลที่สำคัญมาก

แป้นพิมพ์ลัด

  • Alt+Shift+S: เริ่มหรือหยุดเลือกสิ่งที่จะเบลอ
  • Ctrl+Shift+X (Mac: Cmd+Shift+X): ลบการเบลอทั้งหมดในหน้านี้
  • Alt+Shift+M: เปิดหรือปิดโหมดนำเสนอ (Pro)
  • Alt+Shift+H: ซ่อนทั้งหน้าจอทันที
  • Esc: หยุดเลือก Ctrl+Z / Ctrl+Shift+Z: เลิกทำ / ทำซ้ำ

คุณเปลี่ยนแป้นพิมพ์ลัดใดก็ได้ที่ chrome://extensions/shortcuts
