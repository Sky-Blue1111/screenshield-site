Conçu pour les démos commerciales, les appels de support client, les tutoriels, les diffusions en direct et tous les appels Zoom, Google Meet ou Microsoft Teams où vous partagez un onglet du navigateur.

GRATUIT ET SANS LIMITES

  • Flouter au clic : cliquez sur n'importe quel texte, image, cellule de tableau ou bouton pour le flouter. Cliquez à nouveau pour retirer le flou.
  • Tracer une zone : faites glisser un rectangle pour flouter toute une région, comme un graphique ou une barre latérale.
  • Flouter les similaires : cliquez sur un e-mail dans une liste et toute la colonne d'e-mails est floutée.
  • Floutages enregistrés : ils sont conservés pour chaque site et réapparaissent quand vous y revenez.
  • Intensité du flou : réglez le flou aussi fort que vous le souhaitez.
  • Barre noire : couvrez les éléments avec un noir opaque plutôt qu'avec un flou, pour que rien ne puisse être récupéré.
  • Masquer le titre de l'onglet sur ce site : remplacez le titre et l'icône de l'onglet pour que personne ne puisse les lire.
  • Analyse de la page : trouvez les e-mails et numéros de téléphone de n'importe quelle page et floutez-les tous d'un coup.
  • Touche panique : Alt+Shift+H masque tout l'écran instantanément. Appuyez à nouveau pour le réafficher.
  • Annuler et rétablir, raccourcis clavier et menu du clic droit.

PRO, POUR CEUX QUI PARTAGENT LEUR ÉCRAN TOUS LES JOURS

  • Détection automatique sur tous les sites : les données sensibles sont masquées pendant le chargement des pages, sans que vous ayez à cliquer. ScreenShield détecte les e-mails, les numéros de téléphone, les numéros de carte (vérifiés par l'algorithme de Luhn), les IBAN (clé de contrôle vérifiée), les numéros de sécurité sociale américains (SSN), les adresses IP (IPv4 et IPv6), les clés API des services courants, les jetons d'accès, les jetons JWT, les clés privées, les URL de base de données, les secrets dans les liens, les adresses de portefeuilles crypto et, si vous l'activez, les montants.
  • Vos mots-clés : masquez des noms de clients, des noms de code de projets ou des numéros de compte. Les expressions régulières sont prises en charge, et vous pouvez tester un motif avant de l'utiliser.
  • Mode présentation : masque les données sensibles dans tous les onglets ouverts, ainsi que les titres de vos autres onglets. Il s'active automatiquement quand vous commencez à partager dans Google Meet, Zoom ou Microsoft Teams sur le web, et se désactive quand vous arrêtez. Vous partagez depuis une application de visio de bureau ? Appuyez sur Alt+Shift+M.
  • Capture d'écran protégée : prenez une capture d'écran où tout est déjà masqué, puis téléchargez-la en PNG ou copiez-la.
  • Sauvegarde : exportez vos paramètres et vos floutages enregistrés dans un fichier, puis importez-les sur un autre ordinateur.

Pro coûte $4.99 par mois (forfait Mensuel), $29.99 par an (forfait Annuel) ou $49 en paiement unique pour un accès à vie (forfait À vie). Prix en dollars américains. Essayez-le gratuitement pendant 7 jours.

Les paiements sont gérés de façon sécurisée par ExtensionPay et Stripe. Vous pouvez résilier un forfait Mensuel ou Annuel à tout moment.

COMMENT ÇA MARCHE

  1. Épinglez ScreenShield à la barre d'outils.
  2. Ouvrez-le et choisissez Flouter au clic, Tracer une zone ou Flouter les similaires, ou cliquez sur Analyser cette page pour rechercher les données sensibles.
  3. Partagez votre écran. Avec Pro, le mode présentation s'active automatiquement.

Vous débutez ? La page de bienvenue ouvre une page d'entraînement remplie de fausses données.

CONFIDENTIALITÉ

  • Toute la détection et tout le floutage se font sur votre ordinateur. Le contenu des pages ne quitte jamais votre navigateur.
  • Aucune statistique, aucune publicité, aucun pistage. Le forfait gratuit ne nécessite aucun compte.
  • Vos paramètres et vos floutages enregistrés sont stockés par Chrome sur votre ordinateur.
  • La seule connexion réseau se fait vers extensionpay.com, pour vérifier et traiter les achats Pro. Si vous achetez Pro, ExtensionPay conserve l'adresse e-mail utilisée pour le paiement.
  • ScreenShield s'exécute sur les pages que vous visitez afin de réappliquer vos floutages et de masquer les données sensibles pendant le chargement de la page.

Politique de confidentialité : https://sky-blue1111.github.io/screenshield-site/privacy

BON À SAVOIR

  • Chrome n'autorise pas les extensions sur les pages chrome://, le Chrome Web Store ni les pages d'autres extensions.
  • Le texte dessiné dans un canvas (comme dans Google Docs) ou dans des images ne peut pas être lu. Utilisez Tracer une zone pour le couvrir.
  • La détection automatique réduit le risque de fuite, mais aucun outil ne repère tout. Vérifiez votre écran avant de partager quelque chose de très sensible.

RACCOURCIS CLAVIER

  • Alt+Shift+S : activer ou désactiver la sélection pour flouter
  • Ctrl+Shift+X (Mac: Cmd+Shift+X) : retirer tout le floutage de la page
  • Alt+Shift+M : activer ou désactiver le mode présentation (Pro)
  • Alt+Shift+H : masquer tout l'écran instantanément
  • Esc : arrêter la sélection. Ctrl+Z / Ctrl+Shift+Z : annuler / rétablir

Vous pouvez modifier chaque raccourci à l'adresse chrome://extensions/shortcuts.
