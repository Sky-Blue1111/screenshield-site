E-Mails, Telefonnummern, Kartennummern und API-Schlüssel weichzeichnen, bevor Sie Ihren Bildschirm teilen. ScreenShield blendet sensible Daten direkt auf der Seite aus – so bekommen weder die Teilnehmer Ihres Meetings noch die Zuschauer Ihrer Aufzeichnung oder Ihres Livestreams sie zu sehen.

Entwickelt für Vertriebsdemos, Support-Gespräche, Tutorials, Livestreams und jedes Meeting in Zoom, Google Meet oder Microsoft Teams, in dem Sie einen Browser-Tab teilen.

KOSTENLOS UND OHNE LIMITS

  • Per Klick weichzeichnen: Klicken Sie auf einen beliebigen Text, ein Bild, eine Tabellenzelle oder eine Schaltfläche, um das Element weichzuzeichnen. Ein zweiter Klick entfernt die Weichzeichnung wieder.
  • Bereich aufziehen: Ziehen Sie ein Rechteck auf, um einen ganzen Bereich weichzuzeichnen, etwa ein Diagramm oder eine Seitenleiste.
  • Ähnliche weichzeichnen: Klicken Sie auf eine E-Mail-Adresse in einer Liste, und die ganze E-Mail-Spalte wird weichgezeichnet.
  • Gespeicherte Weichzeichnungen: Weichzeichnungen werden pro Website gespeichert und sind beim nächsten Besuch wieder da.
  • Stärke der Weichzeichnung: Stellen Sie die Weichzeichnung so stark ein, wie Sie möchten.
  • Schwärzen: Verdecken Sie Inhalte mit einem schwarzen Balken statt mit einer Weichzeichnung, sodass sich nichts wiederherstellen lässt.
  • Tab-Titel ausblenden: Ersetzen Sie Titel und Symbol eines Tabs, damit niemand sie lesen kann.
  • Seiten-Scan: Finden Sie die E-Mail-Adressen und Telefonnummern auf jeder Seite und zeichnen Sie alle auf einmal weich.
  • Panik-Taste: Alt+Shift+H blendet sofort den gesamten Bildschirm aus. Ein erneuter Druck zeigt ihn wieder an.
  • Rückgängig und Wiederholen, Tastenkürzel und ein Kontextmenü per Rechtsklick.

PRO – FÜR ALLE, DIE JEDEN TAG IHREN BILDSCHIRM TEILEN

  • Automatische Erkennung auf jeder Website: Sensible Daten werden schon beim Laden der Seite ausgeblendet, ohne dass Sie etwas anklicken müssen. ScreenShield erkennt E-Mail-Adressen, Telefonnummern, Kartennummern (per Luhn-Algorithmus geprüft), IBANs (mit Prüfsummenprüfung), US-Sozialversicherungsnummern (SSN), IP-Adressen (IPv4 und IPv6), API-Schlüssel gängiger Dienste, Zugriffstoken, JWTs, private Schlüssel, Datenbank-URLs, Geheimnisse in Links, Krypto-Wallet-Adressen und – wenn Sie es einschalten – Geldbeträge.
  • Ihre Stichwörter: Blenden Sie Kundennamen, Projekt-Codenamen oder Kontonummern aus. Reguläre Ausdrücke werden unterstützt, und Sie können ein Muster testen, bevor Sie es einsetzen.
  • Präsentationsmodus: Blendet sensible Daten in allen geöffneten Tabs sowie die Titel Ihrer anderen Tabs aus. Er schaltet sich automatisch ein, sobald Sie in Google Meet, Zoom oder Microsoft Teams im Browser mit dem Teilen beginnen, und wieder aus, wenn Sie aufhören. Sie teilen aus einer Desktop-App für Meetings? Drücken Sie Alt+Shift+M.
  • Geschützte Screenshots: Erstellen Sie einen Screenshot, in dem schon alles ausgeblendet ist, und laden Sie ihn als PNG herunter oder kopieren Sie ihn.
  • Sicherung: Exportieren Sie Ihre Einstellungen und gespeicherten Weichzeichnungen in eine Datei und importieren Sie sie auf einem anderen Computer.

SO FUNKTIONIERT ES

  1. Pinnen Sie ScreenShield an Ihre Symbolleiste an.
  2. Öffnen Sie es und wählen Sie „Per Klick weichzeichnen“, „Bereich aufziehen“ oder „Ähnliche weichzeichnen“ – oder scannen Sie die Seite.
  3. Teilen Sie Ihren Bildschirm. Mit Pro schaltet sich der Präsentationsmodus automatisch ein.

GUT ZU WISSEN

  • Chrome lässt Erweiterungen nicht auf chrome://-Seiten, im Chrome Web Store oder auf den Seiten anderer Erweiterungen laufen.
  • Text, der auf einem Canvas gezeichnet wird (etwa in Google Docs) oder in Bildern steht, kann nicht gelesen werden. Decken Sie ihn mit „Bereich aufziehen“ ab.
  • Die automatische Erkennung senkt das Risiko eines Datenlecks, aber kein Tool erkennt alles. Prüfen Sie Ihren Bildschirm, bevor Sie etwas besonders Sensibles teilen.

TASTENKÜRZEL

  • Alt+Shift+S: Auswahl zum Weichzeichnen starten oder beenden
  • Ctrl+Shift+X (Mac: Cmd+Shift+X): alle Weichzeichnungen auf der Seite entfernen
  • Alt+Shift+M: Präsentationsmodus ein/aus (Pro)
  • Alt+Shift+H: gesamten Bildschirm sofort ausblenden
  • Esc: Auswahl beenden. Ctrl+Z / Ctrl+Shift+Z: rückgängig / wiederholen

Jedes Tastenkürzel können Sie unter chrome://extensions/shortcuts ändern.
